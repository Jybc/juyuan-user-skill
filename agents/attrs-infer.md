# 淘宝鞋靴类目属性推理

根据商品标题、图片描述和类目属性枚举，推断缺失属性值并给出置信度。

## 输入

你会收到 attrs-check 命令的输出（JSON 结构）：
```
{
  "products": [{
    "num_iid": "123",
    "title": "一字扣凉鞋女厚底露趾仙女风",
    "existing_attrs": {"品牌": "XYZ"},
    "missing_attrs": [
      {"attr_name": "跟型", "valid_values": ["平底","低跟","中跟","高跟","松糕底","厚底","坡跟","内增高"]},
      {"attr_name": "鞋头款式", "valid_values": ["露趾","圆头","尖头","方头","包头"]},
      {"attr_name": "闭合方式", "valid_values": ["一字式扣带","魔术贴","系带","套脚","拉链"]},
      {"attr_name": "风格", "valid_values": ["通勤","仙女风","ins潮","休闲","街头","复古"]}
    ]
  }]
}
```

## 操作流程

### 第一步：语义提取

从标题中分拆关键词，逐一映射到属性维度：

```
标题: "一字扣凉鞋女厚底露趾仙女风"
    ↓ 分拆: 一字扣 | 凉鞋女 | 厚底 | 露趾 | 仙女风
    ↓ 排除: "凉鞋女" 是品类词，不参与属性映射
    ↓ 映射候选:
  "一字扣" → 闭合方式候选: 一字式扣带
  "厚底"   → 跟型候选: 厚底 / 松糕底
  "露趾"   → 鞋头款式候选: 露趾
  "仙女风" → 风格候选: 仙女风
```

### 第二步：枚举匹配

将语义候选与 valid_values 做匹配，选取最佳：

```
语义: 松糕底, 厚底
枚举: [平底, 低跟, 中跟, 高跟, 松糕底, 厚底, 坡跟, 内增高]
    ↓ 同时命中松糕底和厚底
    ↓ 松糕底搜索量 > 厚底 (凭经验)
输出: 松糕底, 置信度 0.95
```

**匹配规则**：
1. 精确匹配 (语义词 == 枚举值) → 置信度 ≥ 90%
2. 包含匹配 (枚举值 in 语义 或 语义 in 枚举值) → 置信度 80-89%
3. 同义词推断 (根据经验) → 置信度 70-79%
4. 无法匹配 → 不输出该属性

### 第三步：图片验证（多模态可用时）

下载商品主图，用多模态模型查看：
- 脚趾是否可见 → 确认 "露趾"/"包头"
- 跟部是否有明显增厚 → 确认 "松糕底"/"平底"
- 闭合方式 → 确认 "一字式扣带"/"魔术贴"
- 整体色调/场景 → 确认风格 "仙女风"/"通勤"/"休闲"

**冲突处理**：图片与标题推断冲突时，以标题为准。图片仅调低/调高置信度 0.05。

### 第四步：输出

返回推断结果 JSON。

```json

      "attributes": [
```

## 约束

- 只输出能明确匹配的属性，不猜测
- 同义词推断需要在 reason 中说明逻辑
- 确保 suggested_value 一定存在于 valid_values 中
- 每件商品最多输出 8 个属性
